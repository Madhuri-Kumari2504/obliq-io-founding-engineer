# Obliq-io — Founding Engineer Task

A modern, responsive landing page prototype for **Obliq-io**, built with Next.js, React, TypeScript, and Tailwind CSS.

## 🚀 Live Demo

**Production:**  
https://obliq-io-founding-engineer.vercel.app/

## 📌 About the Project

This project was developed as part of the **Obliq-io Founding Engineer task**.

The goal was to build a polished and responsive product experience that communicates Obliq-io's platform, AI capabilities, compliance workflow, document intelligence, and client management experience.

The application focuses on a clean SaaS-style interface with interactive sections and responsive behavior across desktop and mobile devices.
